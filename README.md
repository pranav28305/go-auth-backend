# Go Backend — Learning Project

This is primarily a learning project and my first backend project in Go.

The main goal was to get comfortable with Go syntax and learn how to structure a simple backend from scratch. It was also my first time building a REST API, so getting everything working end-to-end was a great learning experience.

The project has a deliberately simple structure. It includes:

* A basic homepage and `/me` endpoint
* User registration and login/logout
* Session-based authentication
* Cookies and authentication middleware
* SQLite database integration
* REST API endpoints for creating, reading, and deleting data
* CSRF protection
* Login rate limiting
* Concurrent session handling with mutexes
* Automated tests and race detection
* Graceful server shutdown
* Expired-session cleanup

This project is intentionally not meant to be a large or production-scale backend. Its purpose was to understand the fundamentals and build something myself without relying heavily on frameworks.

I'm planning to build another project next that will push me further and introduce concepts that I haven't explored yet.
